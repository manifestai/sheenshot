Gerador de fundo a partir do print

Solte um print e veja um fundo criado com as cores dele, em mesh e em degradê. Baixe o resultado em PNG.

Ative o JavaScript para usar o gerador de fundo.

Como funciona esta demonstração

  • O print é reduzido para cerca de 120 px, só para ler as cores.
  • Brancos, cinzas, pretos e cores muito escuras ou muito claras ficam de fora.
  • As cores vivas são agrupadas por tom. As até 4 mais frequentes viram o fundo.
  • Mesh: uma cor em cada canto. Degradê: as duas primeiras cores, em 135°.
  • Se o print for quase todo neutro, o Sheenshot usa o seu fundo padrão.

Sua imagem nunca sai do navegador. Tudo é desenhado aqui, no seu computador.

No app

Esta página é uma demonstração que funciona como as Cores do print do app. No Sheenshot, as Cores do print são um clique no Editor. No Pro, o fundo é criado sozinho depois de cada captura.

Fundos que combinam, direto no Mac.

Capture, clique em Cores do print e pronto. Tudo liberado por 30 dias. Depois, a versão grátis continua para sempre.
